# 📚 Student Record Management System

A simple **Student Record Management System** built with **JavaFX**, **JDBC**, and **PostgreSQL**.  
This application allows you to perform basic **CRUD operations** (Create, Read, Update, Delete) on student records.

---

## ✨ Features

- ✅ Add new student records
- ✅ Display all records in a table
- ✅ Update selected student records
- ✅ Delete student records
- ✅ Clear input fields
- ✅ Input validation (no empty fields)
